## 统一写作与网站展示

本仓库是个人网站的唯一博客来源。原网站的《开张第一天》《用 AI 辅助写作的正确姿势》《GitHub Pages 自动部署踩坑记录》也已迁入 `博客/`，以后直接在这里新增或修改 Markdown，无需在网站仓库维护第二份原稿。

普通 Markdown 可以继续按现有格式写，网站会提取一级标题、正文摘要和文中的日期。若需要精确控制展示信息，可以填写 YAML 信息头：

```markdown
---
title: 文章标题
description: 一句话摘要
pubDate: 2026-10-22
tags: [随笔]
draft: false
---

# 文章标题

正文内容。
```

迁入的三篇文章保留了 `slug` 字段，用于维持原来的个人网站地址，请不要随意修改。图片可以放在本仓库中，通过相对路径引用。

网站每次部署时读取本仓库最新内容；网站同步工作流上线后也会每 6 小时自动更新。需要立即更新时，可手动运行个人网站仓库的部署工作流。
